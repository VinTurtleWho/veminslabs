Headless Deterministic Simulation Core

C++20 // FIXED-POINT ARITHMETIC

The simulation runtime strips away render passes, skeletal mesh updates, and GPU pipelines. All collisions, projectile trajectories, movement speeds, and cooldown timers run through quantized fixed-point integer mathematics to eliminate non-deterministic floating point drift across CPU microarchitectures.

Tick Interval 15.0 ms (66.6 Hz locked)
State Footprint < 8.4 KB / tick instance
Memory Model Linear Arena Allocator
Parallel Capacity 1,024 concurrent workers / node

Policy & Counterfactual Evaluation Network

PYTORCH // ONNX RUNTIME C API

The model processes high-dimensional game states discretized into spatial grid heatmaps and unit feature vectors. A dual-headed value and policy architecture computes value equity (projected win probability) and policy rankings for macro positioning and tactical engagements.

Input Representation Spatial Grid (128x128x32) + Vectors
Forward Pass Time 0.38 ms on standard CPU host
Search Mechanism Batched Monte Carlo Graph Search
Explainer Engine Natural Language Strategy Synthesis
# Policy evaluation & delta computation class StrategyEvaluator: def evaluate_counterfactual(self, sim_state, alternative_action): current_equity = self.val_head(sim_state) branch_state = sim_state.clone_branch() branch_state.apply(alternative_action) simulated_rollout = branch_state.rollout(ticks=120) projected_equity = self.val_head(simulated_rollout) return { "equity_delta": projected_equity - current_equity, "dominant_counterplay": True }

Our inaugural simulation target is 5v5 MOBA dynamics in Mobile Legends: Bang Bang. MOBAs present an ideal research testbed: continuous action spaces, asymmetric fog-of-war, multi-agent coordination, and high-frequency objective prioritization.
